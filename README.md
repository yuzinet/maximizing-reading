# maximizing-reading

読書の効果を最大化するためのWebツール集です。

## 概要

本を読んだあと、その内容を深く定着させ・活用するためのツールをGitHub Pages上で公開しています。
本ごとにツールを作成し、読書体験をアウトプットに変換することを目的としています。

## ツール一覧

| ツール名 | 対象書籍 | 説明 | リンク |
|---------|---------|------|-------|
| 今日の残り時間カウントダウン | 1440分の使い方 | 就寝時刻を入力すると、残り時間をリアルタイムでカウントダウン | [tools/1440-minutes/](tools/1440-minutes/index.html) |

## ディレクトリ構成

```
maximizing-reading/
├── README.md
└── tools/
    ├── 1440-minutes/      # 1440分の使い方
    │   └── index.html
    └── <book-name>/       # 追加予定
        └── index.html
```

## ツールの追加方針

- 1冊の本につき1つ以上のツールを作成する
- `tools/<book-name>/` 配下にHTMLなどの静的ファイルとして実装する
- GitHub Pagesでそのまま公開できるよう、外部依存を最小限に抑える
- ツールを追加したらこのREADMEの一覧を更新する

## 技術スタック

- HTML / CSS / JavaScript (静的サイト)
- GitHub Pages でホスティング
